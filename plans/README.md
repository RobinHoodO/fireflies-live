## Findings considered and rejected (so they aren't re-audited)

- **md.ts → dangerouslySetInnerHTML XSS**: NOT a finding — `esc()` HTML-escapes the
  full string before any markup is built; captured groups land only in element
  text positions; every `style=` attribute is a hardcoded literal, so no
  attribute-injection sink and no link/`javascript:` vector. Confirmed safe for
  LLM/transcript-derived input. (A regression *test* is still valuable → plan 003.)
- **Bridge network posture (DNS-rebinding / CORS / token)**: NOT a finding — loopback
  bind, Host allowlist, OPTIONS→403, bearer token + JSON-only, per-session
  `randomUUID` token held in React state (not localStorage/URL), no-shell `/pi`
  argv, strict sessionId regex, hard-sanitized `/file` slug. Solid.
- **Chrome extension native-host**: NOT a finding — `allowed_origins` locked to the
  single extension id; the host only boots Vite; the CRX signing key is `0600` +
  gitignored.
- **`streamChild` output cap / demo-loop + socket cleanup / buildMd NaN**: NOT
  findings — traced and correct (truncation marker is sent; `running=false` breaks
  stop in-flight loops; the empty-`sentiments` NaN is only referenced inside a
  `length > 0` guard).
- **Denylist-not-allowlist on `/run`, keys served to the browser, transcript sent
  to OpenRouter**: by-design decisions recorded in ROADMAP Phase 3 / "Known
  follow-ups" / ADAPTIVE-NAVIGATOR §5. Implementations match the docs; real fix is
  the roadmap's kernel move (6.3 / 7.4). Not re-reported.
- **`npm audit` clean, socket.io-client current**: no dependency-security findings.
